📊 Matriks Perbandingan Model Kontrol Akses

Model Penentu Kebijakan Dasar Keputusan Kelebihan Utama Kelemahan / Risiko Contoh Penerapan
DAC
Discretionary		 Pemilik Data (Data Owner) Identitas User / Grup pada ACL Sangat fleksibel & mudah digunakan sehari-hari Rentan kebocoran jika pemilik salah memberi izin Permission folder Windows/Linux (chmod), Google Drive Share
MAC
Mandatory		 Administrator Keamanan Pusat (Sistem) Label Klasifikasi Objek vs Clearance Subjek Keamanan sangat ketat; user tidak bisa mengubah izin Kaku & membutuhkan administrasi pelabelan tinggi Sistem militer/intelijen, SELinux, Dokumen Rahasia Negara
RBAC
Role-Based		 Administrator Organisasi / IAM Peran/Jabatan (Role) yang dimiliki User Mudah dikelola untuk ribuan karyawan sesuai struktur Role explosion jika terlalu banyak pengecualian ERP Perusahaan, Portal Akademik (Dosen vs Mahasiswa), IAM
ABAC
Attribute-Based		 Policy Engine (PDP) berbasis aturan dinamis Kombinasi atribut User, Resource, Aksi & Lingkungan Sangat granular & kontekstual (Zero Trust) Kompleks dalam perancangan dan pengujian aturan Cloud IAM (AWS IAM Policy), Zero Trust Network Access (ZTNA)
